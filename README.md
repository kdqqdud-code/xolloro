# XOLLORO — الموقع الرسمي

صفحة هبوط عربية لخدمات التصميم والتسويق الرقمي والمواقع في سلطنة عُمان.

## رابط الموقع المتوقع
https://kdqqdud-code.github.io/xolloro/

## إعداد GitHub Pages
من إعدادات المستودع **Settings → Pages**:
1. اختر **Deploy from a branch**.
2. اختر الفرع **main**.
3. اختر المجلد **/(root)**.
4. اضغط **Save**.
